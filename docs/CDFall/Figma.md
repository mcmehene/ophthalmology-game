# EyeCanDo – Cognitive Walkthrough

## Project overview

The EyeCanDo Figma is a cognitive-walkthrough project. The file contains screen concepts and interaction flows for an experience that guides users through a sequence of scenes and activities represented within the game.

## Version history

| Version | Date | Description |
|---|---|---|
| 1.0.0 | 2026-11-12 | First Cognitive Walkthrough of the EyeCanDo Figma project. |

## What the design contains

The Figma project includes:

- A sequence of scene screens, including introductory screens, the "Fit" and "Eye" character design screens, and the activity screens for the Eye Drop level.
- Visual assets and scene imagery used to illustrate the experience.
- Prototype flows intended to demonstrate how a user moves between screens.

## Interaction and visual design notes

The design uses consistent navigation and interface patterns across scenes. Relevant elements include:

- Home controls.
- Character customization controls.
- Progress dots to indicate completed, current, and upcoming scenes.
- Clear and consistent buttons for primary and secondary actions.
- A final-scene layout that highlights the completion state, reward amount, and achievement badge.

## Backup and documentation

This repository is used to keep reference copies and documentation for the Figma project. It is not currently intended to contain the application's source code.
